# Sheiny – Minecraft Translation Portfolio

Личный сайт-портфолио переводов Minecraft: 15 сборок из предоставленного списка, направления работы, подтверждённый вклад в RTF Extension, контакты Telegram и Discord.

## Публикация

Сайт полностью статический. **Никаких npm, сборщиков, API-ключей или серверной части не нужно.**

1. В GitHub откройте **Settings → Pages**.
2. В **Build and deployment** установите **Deploy from a branch**.
3. Выберите ветку `main`, папку `/(root)` и сохраните.
4. Адрес: https://matteoaq.github.io/TranslationsPortfolio/ (после активации Pages).

Все пути относительные, так что сайт работает как на проектном домене GitHub Pages, так и локально через обычный HTTP-сервер (например, `python -m http.server`).

## Правки

- Список из 15 сборок и описания: `app.js` → `projects`.
- Цвета и адаптивная вёрстка: `styles.css` → `:root`.
- Тексты разделов и ссылки: `index.html`.
- Discord `sheiny__` копируется кнопкой – публичная ссылка на профиль Discord требует числового user ID, из username её не составить.

## Галереи переводов KennnyMC

Ссылки на примеры реальной локализации вынесены в `projects[].translationShots` (app.js), когда в публичном посте KennnyMC указан соответствующий альбом `@kennnyscrin`. Часть ссылок из постов повторяется между разными сборками, поэтому потенциально ошибочные дубли не использованы. Открытие Telegram-альбомов может требовать авторизации/доступа.

## Источники / использование иллюстраций

Иллюстрации карточек и галереи загружаются с внешних сайтов (официальные страницы модпаков на CurseForge, imgur и minecraft.fr). Они показывают оригинальные сборки, **не являются доказательством наличия перевода на изображении**. В интерфейсе для каждого публичного снимка есть переход к источнику. В некоторых случаях внешний CDN может блокировать отображение: предусмотрен градиентный фон.

RTF Extension: https://www.curseforge.com/minecraft/texture-packs/rtf-extension – раздел Sheiny (Genshin Instruments, Serene Shrubbery); также RTF+ 2.5.0 и 2.5.1.

Рекомендация на будущее: заменить внешние изображения собственными скриншотами EN / RU, оптимизированными в WebP, с разрешения правообладателей. Не публиковать коммерческие архивы-патчи непосредственно из портфолио без разрешения.

## Тесты

- Фильтр тематики и поиск по названиям, без перезагрузки страницы.
- Модальные карточки, галерея, копирование Discord.
- Адаптивная вёрстка для смартфонов и компьютеров; поддержка `prefers-reduced-motion`.
- Нет форм, трекеров, сбора данных или зависимостей в рантайме, кроме Google Fonts и изображений.
